# 官方 SDK：先核实语义，再设计控制

依据 [O6](sources.md) 父任务对 2026-10-10 文档的已核实摘录；本次未成功读取官方页面或 `data.body_md`。以下不是本环境实测，也不是可直接运行的 SDK 示例。LBot/O6、双7轴与4路RGB属于通用平台/默认模板信息，不直接等于四个参赛组的强制硬件规格；独立审计未取得手册不否定父任务已读原件事实。

## 已知接口和高风险误读

| 文档事实 | 工程处理 |
|---|---|
| LBot A7 双臂，每臂 7 轴；两只 O6 各 6 主动电机 | 不把手简化成有反馈的二指夹爪；手命令与观测分开记录 |
| `rabo_robolib.LbotDualArm(mode='sim')`；`arm_left` / `arm_right` | 只作为后续适配器核对项，本仓库不导入或初始化 SDK |
| 位姿参考 `base_link`，米/弧度 | 明确 T_base_camera 方向、旋转约定、时间戳；禁止 mm/m 混用 |
| 无公开手位置/力反馈 API；`get_joint_angles` / `get_finger_forces` / `grasp_force` 不存在于所读手接口 | 不能虚构力闭环、关节观测或填零假装反馈；视觉证实物体跟手运动 |
| 手 `set_force` / `set_speed` 仿真不生效 | 不用这两个参数解释仿真抓取改善，试验中记录实际生效控制量 |
| `close` 返回成功不代表抓住 | 指令接受、接近、抓持、抬离、放稳分别记状态 |
| 仿真 `move_to(linear=True)` 仍为关节插补 | 显式抬升→平移→下降路点仍需整段轨迹、肘姿和碰撞验证；离散安全点不保证点间安全 |
| 通用平台存在物体 pose/TF 真值、`SetEntityPose`、`attach/detach` | API 存在不等于比赛允许；不进入策略控制链，不用 attach 模拟成功抓取 |
| 相机 `rgb8`、`camera_info` 针孔内参；光学轴 z 前 x 右 y 下 | 转 OpenCV 图像时明确 RGB/BGR；内参随分辨率改变而更新；畸变按实际消息处理 |
| 六月 `rabo_robocap` 与十月 `rabo_robolib` 不同 | 以复制的实际模板和依赖锁为准；不要求 LLM，不把旧文档启动命令当新平台 API |

## 控制输入白名单草案（待实际模板/官方许可确认）

这是一份设计约束，**不是已经实现的运行时隔离器**。未来适配层默认拒绝未知来源，并为每条观测保留 producer、时间、frame、校准版本。合法输入的内容和来路都要核查。

| 候选可用输入 | 批准前需核实 | 明确排除 |
|---|---|---|
| 相机 RGB、camera_info | 相对话题名、编码、时钟、允许的相机列表 | 物体真值分割/深度/pose 未获授权不能混入 |
| 机器人本体实际反馈 | 模板确实提供哪些臂/手状态；命令回显不当观测 | 不存在的手力/位置反馈 |
| 自行标定的 T_base_camera | 来源是允许的 RGB、标定物/机械测量；验证留出点 | 从仿真实体位姿直接抄外参，除非官方明确授权 |
| 白名单机器人连杆 TF | 逐帧检查 producer 与允许 frame 对，仅机器人运动学 | 物体 frame、场景对象 frame、经 TF 间接拼出的真值位姿 |
| 自己从合法图像估计的物体状态 | 保存检测证据、置信度和不确定性 | 仅改字段名的模拟器真值 |

标定数据与模型标签的合规边界另行询问，不把“训练不用作在线决策”当作自动许可。开发评估如获准访问真值，也必须与策略进程隔离且不得向动作选择返回信号。

## 接入验收顺序

1. 只读检查复制应用及 `agent_system`：分支、模板提交、Python/ROS/SDK 版本、依赖、README、费用；由创建者邀请队友。现在均未执行。
2. 枚举实际话题，核对 `ROS2_NAMESPACE` 与相对话题、`/clock`、TF 重映射。检验图像和状态时间是否同源，防止跨队伍话题和旧帧。
3. 静态图像完成内参、外参和桌面/不同高度验证。桌面单应性只适于所在平面，不能将底层映射直接用于高层中心。
4. 获授权后仅在仿真单臂、小幅运动：测试阻塞/异步、超时、失败返回、停止机制、动作队列；验证肘姿/自碰和另一臂固定姿态。
5. 抬起单块，视觉比较预期相对运动，放开后手退出支撑并观察至少 3 秒。再引入堆叠、遮挡与恢复。

未来适配层至少需要“带来源的观测”“动作接受/完成/超时”“可中断动作”“视觉后验”四类内部契约。这些是本项目设计名称，尚无官方方法签名；不创建占位成功返回、不写猜测的 SDK API。
