## 后续实测阶段参考步骤（当前暂搁）

1. 用户在[登录页](https://www.rabokit.com/login)完成合法登录；如触发注册/新协议或公众号关注，由用户决定。**输出只需确认登录完成，不传凭据。**
2. 登录后先只读查看账户资源、运行/训练单价、免费额度、模型费用、自动启停说明。不要进入agent编辑区或display分享页。**输出：可否零费用运行小实验、具体适用资源/额度、会触发计费的操作。**账户详情无需整页导出。
3. 优先寻找不唤醒运行环境的模板下载/只读Git信息入口。父任务暂未找到；若仍没有，先由用户明确确认可接受的费用/额度和范围，再进入`agent_system`。当前授权不包括计费执行，不能默认为批准。
4. 获授权后确认正确比赛应用/工程/分支，仅导出源码、依赖清单、SDK版本、启动说明和可公开接口说明。不要改分享权限、邀请队友、生成正式提交链接或导出secret。**输出：实际模板快照/提交、文件哈希、可核实方法签名。**
5. 用本仓库只读`preflight --template`审查后实现实际适配器。先导出RGB/camera_info、合法外参来源、实际本体状态、话题/命名空间和时钟样例；不导出物体TF/pose真值。**输出：传感器样例与来源证据；无需先执行动作。**
6. 在确认免费/已授权资源及安全停止机制后，依次做只观测、单臂小幅路点、单块抓放。保存与当前契约一致的原始图像、动作/反馈、阶段与失败日志，再批量评估。每次提升反馈层级必须有对应真实证据。

无需实际平台的离线协议/策略/异常与噪声验证已完成验收收束，登录不作为本轮阻塞。这些步骤只供后续实际接入阶段参考；本轮不重复申请登录或费用操作。

## 实际适配前必须提供的输入/输出

| 需要输入 | 接入后应产生的输出 |
|---|---|
| 模板版本、依赖及确证SDK源码/方法说明 | 源锁、实际方法映射和最小启动命令；未确认方法不写调用 |
| 允许RGB话题、rgb8/camera_info、可审查校准T_base_camera来源 | 有版本、时间和frame的RGB观测；当前合成内外参不能用于官方相机 |
| 实际本体反馈或经核实的机器人运动学 | 不填零冒充O6反馈；命令回显与测量分开；没有可用本体状态则修改验证策略 |
| 动作接受/完成/取消/超时语义，停止机制 | 有界返回的内部Backend实现；阻塞SDK须有实际可行取消路径，不能靠日志宣称物理停止 |
| 官方场景、供应区/砌筑区、可用标定物、执行预算 | 合规配置与可重复试次；当前合成区域/阈值不当作官方几何 |
| 账户资源与明确授权范围 | 每次执行记录环境/资源；无需开模型、训练或真机 |

`move_to(linear=True)`在所读仿真SDK仍关节插补，真实路点必须核验整段肘姿/避碰。手close返回成功不等于抓住，set_force/set_speed仿真不生效，不捏造力/位置反馈；SetEntityPose/attach/detach与物体真值TF不用于策略。官方真值决策禁令与输入许可不会因获得登录而自动改变。
