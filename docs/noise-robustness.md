# b947d9e历史：单块RGB噪声诊断与多帧定位

**本页是历史结果。父任务后续确认M1：均值判稳会误接受持续运动。当前定位/稳定已分离，完成率回落见[逐帧修复](motion-stability.md)；不要把本页11/18当作当前稳定能力。**

本轮只运行标准库的离线RGB运动学夹具，没有机器人SDK、官方平台、接触物理、模型调用或训练。它验证程序的观测/控制/记录逻辑，不能证明比赛抓取成功率。研究与规则文件仍以2026-10-12北京时间的来源锁为准。本轮运行日期、源码指纹、参数和逐试次结果另锁入机器可读证据。

## 根因与改动

`9a991efe36d67cfeb97b4396e204bd78b227b2e3`的18例噪声扫描仅6例完成。相同的单帧基线重新运行仍应得到6/18；这18个种子/条件已看过，**属于匹配回归，不是未见数据**。例如1px、seed=0放置后的静止块，逐帧重建位置范围约为x14.95/y34.77/z24.11mm。单帧估计既超出稳定/高度阈值，也触发重抓，随后在关闭前停止；2px还可能令单帧stereo residual拒绝。彩色块检测没有丢失，不等于3D估计可靠。

因此保留原始单帧RGB/估计，额外添加静止时的多帧像素估计：

1. 同一颜色、两相机、连续序号、捕获间隔≤0.25秒、本体末端变化≤3mm；缺失/歧义不能补值。静止窗口9–49帧，先在像素域均值化，再三角测量，避免先重建后筛选有利的3D点。
2. 从四维像素样本协方差和本地三角测量雅可比传播随机误差；每轴使用2倍标准误，显著正时间相关时减少有效样本数。扫描时间分段均值差，避免把窗口末端突变平均掉；像素跨度/身份/时序异常均重置。**这不是校准过的置信区间，更不是联合95%覆盖保证**。
3. 接近/抓持阶段允许较粗估计，但关闭前仍检查“均值距测量末端 + 随机误差半径 + 2mm假设余量≤30mm”。抬升证据扣除前后高度不确定度后仍须≥60mm。释放前两次停稳重验持有。
4. 搬运逐帧检查颜色、可见性、捕获覆盖及相对于“RGB已观测持有偏移+测量末端”的像素创新；不使用命令目标或隐藏场景状态替代观察。4px创新门属于实验参数，不是30mm三维抓持或碰撞保证；端点还必须重新满足保守三维持有界，否则不会下降/释放。
5. 释放/撤手后使用≤7.5mm随机误差半径的窗口。目标25mm、稳定15mm、高度12mm、手分离80mm、静置3秒、动作1.8秒及总试次30秒阈值均未放宽；距离/高度加上误差余量，手分离扣除误差与允许末端变化。证据不确定时在停放位等新图像；确认偏离目标才重抓。窗口缺图/空窗/时间变化/滚动截掉未验证帧，都会重开稳定计时。

`robust_observations=true`为CLI与推荐配置；显式`Config()`仍采用旧单帧模式，便于历史夹具和对照。`--raw-observations`可运行对照。两种模式的终止、停止请求和异常分类共用已加固逻辑。没有根据已知目标或桌面高度把估计“吸附”到正确答案，也没有将评估器物体真值放入控制输入。

## 分辨率、外参和真实部署假设

合成场景为160×120、fx=fy=180px、两相机基线760mm。目标附近光学深度约1.228m，单相机横向量级Z/f约**6.82mm/px**。本夹具在目标处对左u/左v/右u/右v各加1px，重建坐标变化约：

| 扰动 | Δx/mm | Δy/mm | Δz/mm |
|---|---:|---:|---:|
| 左u +1px | 2.111 | −9.252 | 5.390 |
| 左v +1px | −0.494 | 0.063 | −4.074 |
| 右u +1px | 4.390 | 7.862 | −4.512 |
| 右v +1px | 0.966 | −0.117 | −3.603 |

可见1px不是1mm，深度误差取决于基线/视角。相同视野下图像尺寸和焦距像素同时翻倍，同样1px误差的米量级约减半；对现有低分辨率图片插值不增加信息。官方相机实际分辨率/焦距未核实，以上不是官方设备参数。

多帧均值只能减少近似零均值随机扰动。共同外参偏移、像素固定偏置、镜头畸变、时钟偏差、颜色分割的非中心表面点、未知手块刚性偏移都不会因为stereo residual小而消失。2mm绝对余量和1mm差分余量是**待真实标定验证的预算假设**，不是实测误差上界；超过它们时，本程序不能认证真实25/15mm条件。

后续实测必须独立测量内参/畸变、相机至base_link外参及其不确定度，用工作区多位置多高度的留出标定物检查绝对/相对误差；静态连续录像估计分割偏置、相关性和有效样本数，运动录像检查曝光/延迟/同步；本体位姿必须来自允许的测量反馈。先估计所需毫米预算，再决定原始分辨率、基线和观察时长。手无公开反馈时仍需要视觉抓持与释放检查。本次没有执行这些实测。

## 验证设计与证据边界

开发阶段只用seed20/21选择采样策略并修复证据一致性。参数冻结后做三类小扫描。首次全扫描因评估脚本漏传后端类型导致目录重名而中断；修正夹具路由、增加唯一名检查，保留已完成匹配数据，再完成未见/负例扫描。默认几何未见种子在中断扫描中已观察，重跑前后没有改参数；其他三种几何/相关性夹具首次运行。此过程和每批夹具源散列均记录在证据中。

- 匹配回归：raw/robust × 0/1/2px整数抖动 × 0/10mm共同外参平移 × seed0/1/2。相同几何、阈值与噪声生成器；控制策略读取帧的次数不同，随机流消费不同，因此不是逐帧同一录像的配对试验。
- 未见夹具：seed100/101/102；默认几何2px、240×180/f270的相同视野2px、600mm基线2px、四帧相关的1px噪声。它们仍来自同一玩具渲染器，不是跨真实数据集泛化，也不足以估计比赛概率。失败照录，不按结果调整参数后仍称未见。
- 负例：两个模式各14个故障，覆盖稀疏稳定窗、总/动作超时、未撤手、搬运遮挡/滑落、持续运动、虚假到位、真值字段、相机不同步、陈旧/重复数据；另3例稳定末端20mm突变。后者可以重新观察≥3秒后恢复成功，不能把原来的窗算成功。评估器单独检查隐藏最终位置/末端突变后时间；这些真值仅用于验证，不发送给控制器。

回放从原始PPM重新检测，另一个实现独立重算均值/协方差/时间相关折算与几何传播，再重建close/lift/release和稳定全过程。哈希仅检查记录一致性；重新编造一整套自洽图像、本体反馈和日志仍可伪造物理执行，返回真实性标志保持false。v1/v2历史回放保留。

```bash
python scripts/noise_validation.py --output runs/noise-check --workers 2
python scripts/check.py
python -m hand_competition.closed_loop run --pixel-jitter 1 --seed 20 --output runs/robust-demo
python -m hand_competition.closed_loop run --raw-observations --pixel-jitter 1 --seed 20 --output runs/raw-demo
```
