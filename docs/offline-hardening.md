## 校准与噪声

新增独立闭式针孔夹具：生成像素不调用生产`Camera.project/ray`，用已知解析值检验三角测量和米/像素单位；再扫描像素扰动及共同外参偏移，误差在评估器中计算，已知坐标不会送给控制器。合成RGB场景另注入像素抖动和标定平移，在冻结源版本运行并回放。

```bash
python scripts/robustness.py --output runs/my-robustness
python scripts/check.py
```

共同外参偏差可产生极小stereo residual但系统性位置误差，不能用自洽残差代替绝对精度。图像抖动可能导致停止/窗口重置，阈值没有为了通过数据而放宽。扫描仍是离线证据，未证明真实照明、材质、遮挡、多物体关联、十块堆叠、接触物理或真实标定可靠性。
