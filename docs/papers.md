# 论文解读：把作者结果转为本赛可检验假设

原始HTML关键章节已实际读取，版本、作者、许可见 [P1–P4](sources.md)。下述迁移判断与实验设计是本项目推论；没有复现论文或产生比赛成功率。

## P1 — ACT（2023）

Tony Z. Zhao、Vikash Kumar、Sergey Levine、Chelsea Finn 的 [原文 IV–VI](https://arxiv.org/html/2304.13705v1) 用多视角图像和关节状态预测动作片段，通过时间集成改善连续动作；CVAE处理示教差异。作者设备为双6轴臂加夹爪，输出14维目标，约80M参数；IV-C报告11GB RTX2080Ti约5小时训练、约10ms推理。任务结果不可直接外推到O6灵巧手。

**本赛假设**：若几何定位已可靠，但闭合与抬升配合反复滑落，局部ACT可能优于手工固定时序。先适配实际可观测状态与手命令，不能编造手关节反馈。将“接近→闭合→抬升”作为有限技能，输出仍经过范围和超时检查。

**最小对照**：同一批留出摆放条件，对比固定手型状态机与局部ACT；统计抬离、滑落、碰撞、3秒稳定、失败恢复。只在增益能覆盖采数成本且不降低整场保分时采用；不因验证loss下降就宣布成功。示教数量先由学习曲线决定，“10分钟示教”不是本赛数据预算保证。

## P2 — Diffusion Policy（2023，读取2024 v5）

Cheng Chi等的 [原文 §2–3、§9](https://arxiv.org/html/2303.04137v5) 对动作序列做条件去噪，采用滚动执行窗口处理多种有效动作。§3.4报告特定DDIM配置在3080上约0.1秒推理；§9明确提及示教不足和推理成本限制。所读扩展版含双臂任务，不能仅按早期单臂Push-T仓库示例概括整篇论文。

**本赛假设**：可行抓姿确有多个模式、平均动作会导致抓空时，DP可能比简单回归适合；如果抓取模式单一，增加采样开销没有明确收益。滑落来自标定错误时换生成模型不治根因。

**最小对照**：使用与ACT相同示教和留出布局，冻结归一化/观测窗口；分别报告策略计算时间、相机到执行总延迟、执行片段长度及最终得分。缩短执行窗口测试反馈响应，测是否因推理变慢而来不及纠偏。不能把论文“平均提升”转换成本赛加分幅度。

## P3 — OpenVLA（2024）

Moo Jin Kim、Karl Pertsch、Siddharth Karamcheti等的 [原文 §3.2–3.5](https://arxiv.org/html/2406.09246v3) 将RGB与文本映射到离散动作token。原版7B模型使用单臂末端动作空间，训练数据约97万轨迹；论文报告bf16推理约15GB、4090约6Hz，预训练为64张A100约14天。代码MIT不等于底层权重免于Llama2条款。§6明确原版仅支持单张图像，并指出高频双臂控制与可靠性仍有不足。

**本赛判断**：任务固定、颜色少，语义泛化未必是瓶颈；四路RGB、双7轴臂和双O6动作空间迁移才是成本。不能把7维动作误读为“支持7轴机械臂的所有控制”，更不等于控制双灵巧手。此时不值得为宣传上的通用性投入大规模训练。

**后续小试前提**：只有正式任务出现可验证的语义选择困难，且资源/许可明确时，先将模型用于离线目标选择对照，评价其是否优于颜色几何；不让未校准动作头直接驱动机器人。即使目标选择有增益，也不能顺推端到端VLA可用。

## P4 — FoundationPose（2023预印本，CVPR 2024）

NVIDIA的Bowen Wen、Wei Yang、Jan Kautz、Stan Birchfield在 [原文 §3–4与附录](https://arxiv.org/html/2312.08344v2) 将对象建模、候选姿态细化与选择结合；可使用CAD或参考视图建立对象表示。方法和公开demo需要RGB-D。作者3090设置下初始化约1.3秒、跟踪约32Hz；初始化不能按跟踪速度预算。代码/数据的非商业研究评估限制与论文CC BY是两回事。

**本赛判断**：若工具纹理/遮挡让几何方法失效，6D跟踪可能有用；但默认只有RGB，当前不能满足接口。没有CAD的模式仍需对象建模和深度，不能借“免微调”忽略输入条件。附录§5.4还指出外部2D检测的漏检/误检会成为瓶颈，无纹理叠加强遮挡也可能让姿态估计失败。

**有条件对照**：仅在官方允许深度、对象模型和相应用途时，用合法图像建立离线测试集，与几何方法比较遮挡后的重定位、对称歧义、延迟、有效放置误差；初始化mask不能用内部真值。若几何已满足误差预算，则不引入这一复杂栈。

## 从文献到获胜路线的共同约束

这些论文证明了各自设定下的方法价值，没有证明本赛硬件、规则和五分钟时限下的胜率。最可迁移的是“短时动作片段、持续视觉后验、全部试次评估”的思想，而非现成权重。当前主要瓶颈是输入合法性、相机到base_link标定、动作语义、可靠抓放和恢复；先建立这些基线再选择模型。
